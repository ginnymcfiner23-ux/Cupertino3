## 2. California: NO inheritance tax, NO state estate tax

| Fact | Value | Source |
|---|---|---|
| California has no inheritance tax | Repealed by Proposition 6 (June 1982); never reinstated | California FTB bill analyses (SB 378, SB 726) — https://www.ftb.ca.gov/tax-pros/law/legislation/2019-2020/SB378-032519.pdf |
| California has no state estate tax | "Pick-up" tax tied to federal credit; federal credit repealed for deaths after 2004 → state tax is zero | FTB SB 378 analysis — https://www.ftb.ca.gov/tax-pros/law/legislation/2019-2020/SB378-032519.pdf ; FTB SB 726 analysis — https://www.ftb.ca.gov/tax-pros/law/legislation/2017-2018/sb726-032317.pdf |
| California estate tax statute still on books | Rev. & Tax. Code §13302 (collects nothing) | FTB analyses (same links as above) |
| Estate tax exposure for CA residents | Solely federal estate tax above $15M/person (2026) | IRS estate tax page — https://www.irs.gov/businesses/small-businesses-self-employed/estate-tax |

## 4. Proposition 19 — intergenerational transfer exclusion (effective Feb 16, 2021)

| Fact | Value | Source |
|---|---|---|
| Prop 19 parent-child exclusion applies ONLY to the family home (principal residence of transferor) | Rental, vacation, investment, commercial property: NO exclusion → reassessed to full market value | BOE LTA 2022/051 (official) — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| Transferee (child) must live in the home as primary residence within 1 year of transfer AND file homeowner's/disabled veterans' exemption | Exclusion lost if not met → full reassessment | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| Value cap: new taxable value = market value at transfer, minus the $1M allowance (added to factored base year value) | If market value ≤ factored base year value + $1M: no reassessment; above: excess added | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| $1M allowance is inflation-adjusted | 2025-2027 period (Feb 16, 2025 – Feb 15, 2027): $1,044,586 (BOE) | BOE adjustment (cited via legal summaries; original BOE publication) — flag: verify latest BOE adjustment notice on boe.ca.gov |
| Claim form | BOE-19-P; file with county assessor within 3 years of transfer (or before sale to a third party) | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| Date of death = date of transfer for property tax purposes | Claim deadline runs from date of death, not distribution date | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| If the inherited family home later becomes a rental (heir moves out) | Exclusion is removed; new value established as of Jan 1 lien date following move-out, based on market value at date ownership was obtained | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| If 2+ children inherit, only one needs to occupy; if that child moves out, another must move in within 1 year | Exclusion continues | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| Old Prop 58 rules (primary residence any value + $1M of other real property) | Repealed for transfers on/after Feb 16, 2021 | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |
| Trust transfer counts as a transfer at date of death | Same rules as outright inheritance | BOE LTA 2022/051 — https://www.boe.ca.gov/proptaxes/pdf/lta22051.pdf |

| Fact | Value | Source |
|---|---|---|
