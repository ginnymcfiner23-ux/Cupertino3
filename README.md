# California Property Inheritance Guide

A privacy-first, static GitHub Pages dashboard for organizing the live/rent/sell decision around a future California home inheritance. The current-law reference point is November 6, 2026; all household-specific property values, tax bills, rents, utility bills, and insurance estimates are withheld from the public site because they are unverified and sensitive.

## Pages

- Overview / executive summary
- Decision guide
- Projections (formulas and blank unsupported values)
- Inheritance steps
- Tax and property law
- Operating costs
- Flagged for review
- Official sources

## Local preview

Open `index.html` in a browser or serve this folder with a static HTTP server. No package install is required.

## Privacy and evidence policy

Do not add addresses, parcel identifiers, names, trust documents, account identifiers, exact property valuations, household rent/bill figures, or other personal/financial information. Unknown and unverified figures must stay blank and be listed on Flagged for Review. The site is educational planning material, not legal, tax, insurance, investment, or appraisal advice.
