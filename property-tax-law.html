Property tax law

The California rules that decide what happens to the assessed value when Property C changes hands. This is the page that drives every number in the analysis, so every row below is cited to the Board of Equalization or to the Revenue and Taxation Code.

The one-sentence version. Under Proposition 19 an inherited home keeps its low Prop 13 assessed value only if the transferor lived there, the heir moves in within one year, the heir files two forms on time, and the market value is within the factored base year value plus an indexed $1,000,000. An inherited rental gets nothing.

What this means for Property S

Only the unit the transferor occupies as a principal residence qualifies as the family home; the rest is reassessed at full cash value

California State Board of Equalization, LTA 2026/026 (Q5)

Property S is a three-unit building with the owner in one unit. If it were ever transferred to the next generation under Prop 19, only the owner-occupied unit and its homesite would qualify; the two rented units would be reassessed at full cash value. That is worth knowing now, while there is time to plan around it.
