# COSTS — Utilities, Insurance, Maintenance

## Verified rate structures (official)

### Cupertino water/sewer (City of Cupertino, effective Jan 1, 2026)
- Water tiers (per 1,000 gal): $5.80 (0–5,000 gal), $7.30 (5,001–10,000), $10.42 (10,001–19,999), $14.60 (20,000+)
- Sewer usage: $5.46 per 1,000 gal; Storm drain base: $12.18/mo
- Base charges: 5/8"-3/4" meter = $15.69/mo (water) + $14.68 (irrigation) + $5.95 (sewer) — see table
- Example: 6,000 gal/mo water+sewer+storm ≈ (5.80×5 + 7.30×1) + sewer(6×5.46) + storm(12.18) + base(≈$35) ≈ $65–85/mo
- User estimate: $100–150/mo (flag: user-provided; verify on actual bill)
- Source: https://cdnsm5-hosted.civiclive.com/UserFiles/Servers/Server_1881137/File/Residents/Water/PDFs/Billing/2026/2026%20Rates%20Table%20Summary%20Final_accessible%20(1).pdf

### SF water/sewer (SFPUC, effective July 1, 2026 — FY 2026-27)
- Average single-family combined water+sewer bill: ~$171/mo (before increase) → ~$189/mo (July 1, 2026) → ~$212/mo (July 1, 2027)
- Water rate schedules: 5/8" service $19.65/mo + tiered volumetric; Sewer: base + volumetric + stormwater component
- Multi-unit: sewer capacity charges based on ERU; 3-unit property water+sewer can run $330–$400/mo (user-provided; plausible at SFPUC rates)
- Source: https://www.sfpuc.gov/accounts-services/water-power-and-sewer-rates/proposed-water-sewer-rates-2026 ; https://www.sfpuc.gov/sites/default/files/accounts-and-services/Rates_Schedule_Water_Sewer_2026-7.pdf
